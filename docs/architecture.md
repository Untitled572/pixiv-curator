# 架构概要

更新日期：2026-10-02。当前只实现项目骨架；业务实现按 [开发计划](development-plan.md) 推进。

详细的状态、数据、任务与 API 以 [详细设计](detailed-design.md) 为准，本文件仅作快速导航。

## 确认的方向

- Go 为主，第一版单体服务、SQLite、进程内后台 Worker。
- 导入关注并推荐画师；推荐必须预览、手动确认后才采集。
- 本地采集名单独立于 Pixiv 关注，不默认执行远端写操作。
- 持久保存作品 ID、每页链接、元数据和偏好。
- PicHub 管理原图下载、文件缓存、收藏和分发。
- Curator 可以提供固定图片页的流式代理，但不持久存原图。

## 数据流

```text
关注同步 / 推荐候选
        ↓
用户确认画师
        ↓
后台增量采集 → SQLite 作品与分页目录
                         ↓
                    偏好过滤与选图
                         ↓
                 JSON + 固定图片页地址
                         ↓
              PicHub 下载 / 缓存 / 收藏
```

后台负责 Pixiv 请求、推荐、同步与修复；前台选图读取本地目录。候选预览不会进入正式供图范围。
