# 发现画师改造计划

2026-11-21 · 规划，待实施

供图抽样由 [供图随机算法改造计划](image-selection-plan.md) 单独跟踪。

## 目标与配额

- 普通手动换批最多 16 位，目标为 9 位算法推荐、6 位榜单随机、1 位随机 ID。榜单或随机 ID 名额不足时，由符合年龄和样本规则的算法候选补位。符合条件的候选仍不足时按实际数量展示。
- 定向发现也最多 15 位，继续按标签、年龄、AI 和主要方向生成候选，不套普通三池配额。
- 移除空闲 5 分钟自动补池。加入图库和不感兴趣只移除已处理卡片。只有手动换批才生成下一批。取消已有的待运行补池任务，阻止已经领取的旧补池任务覆盖新结果。保留既有推荐和审阅历史。
- 新轮次继续排除上一批候选，只避开紧邻的一批。历史未操作和弱跳过均不改变画师可推荐资格。已收录、已拒绝和已屏蔽的规则延续。

| 项目 | 新参数 |
| --- | --- |
| 年龄超额 | 成年偏重组最多比原目标多 1 位 |
| 未知内容 | 算法池最多 1 位 |
| Pixiv 相关画师来源 | 约 60%，9 位算法名额的目标约 5 位。按最大余数分配到内容组，并按来源可用性补位 |
| 召回与总预算 | 保留 60 位召回、80 次请求的上限，优先把余量用于全年龄补召回和校验 |
| 独立探索 | 2 页历史榜单，其中一页从通用榜单前四页随机抽取；另取近期日榜确定随机 ID 上界，随机 ID 最多探测 5 次，找到 1 位即停 |

## 年龄配额与召回

图库和候选使用相同的画师年龄分类口径。近期最多取 30 件可用作品，至少有 8 件明确分级，且明确分级比例至少 75%。R18/R18G 合计占明确分级的比例为 0 时归全年龄，介于 0% 与 30% 之间归混合，达到 30% 归成年偏重。证据不足归未知。样本分级和画师分类分开保存；卡片仍只展示最多 3 件代表作，全年龄组优先展示明确全年龄作品。普通发现页的 R18/AI 下拉框仍只影响展示。

已收录画师按同一口径决定内容组目标，上一轮新加入画师仍以 0.2 计权。优先在同内容组内互补来源，再按内容上限跨组补位。全年龄种子的相关作品查询只用明确全年龄的种子作品，先复用已取得的元数据，按预算补查临近入选候选。

在裁剪前记录不同种子对候选的命中，同一种子的不同端点不重复计种子。去重、来源和命中计数按轮次持久化。按来源和年龄记录召回、去重、准入、样本校验、配额前和最终结果，以及缺额和补位原因。单独统计随机 ID 实际发出的请求和命中数。

## 内容排序与展示

现有回归保留作为离线对照。统一训练和新候选的特征视图，最多 3 件作品，优先 2 件高收藏加 1 件近期。从内容评分移出召回来源。使用显式词表、一次方 IDF 和 L2 归一化；剔除收藏量标签，并限制泛标签与罕见标签的影响。分类不足时保留未知。新审阅动作与弱反馈冻结当时的样本特征。

先评估 IDF 余弦相似度、收缩后的显式负中心与饱和的不同种子共现。关注同步形成长期正向画像，显式接受和拒绝用于审阅评估。小组、同分或弱证据保持近均匀抽签；正常组用带上限的分位权重，初始 P90/P10 上限 4:1。待有足够可用显式负例后再评估稀疏逻辑回归。保留既有逐图赞踩对算法池的轻微影响。

算法卡片显示真实排序参考分。榜单探索继续随机混排，去掉插值分数；随机 ID 置底且无分数。沿用不新增探索徽标的页面设计。独立探索的入选权重不使用兴趣评分或跳过权重。

## 手动换批的弱反馈

### 有效曝光与结算

只有普通推荐中成功被手动换批实际替换的当前卡片，且仍未加入、未点不感兴趣，才可能结算弱跳过。

前端 IntersectionObserver 以卡片可见面积达到卡片/视口可容纳面积较小者为目标，至少一张成功加载的代表作确实可见，且发现页在前台连续停留 1.5 秒。隐藏、离开视口或图片失败时重置计时。移动端超出视口的卡片按可见区域判定；图片下载或预取本身不算曝光。筛选隐藏卡片、未滚到的卡片、定向搜索及修改筛选产生的换批不结算弱反馈。

手动换批提交父轮次和有界的有效曝光候选 ID。后端核对当前轮次、候选身份和审阅状态，按展示轮次与画师幂等结算。换批失败且仍显示旧卡片时不落永久弱反馈。获取新一批时冻结输入，避免重试改变候选与反馈集合。过期轮次或重复提交不得增加次数。

### 两层作用

- 画师级：记录最近 45 天内每次有效跳过，按每条事件随时间线性衰退得到有效次数 k_eff。算法池抽签权重乘 max(0.25, 0.70^k_eff)。近时一次为 0.70、三次约 0.343，达到上限后最低为 0.25。45 天无新跳过后完整恢复到 1.0。该因子不剔除任何画师。
- 内容级：与显式不感兴趣分开维护弱负中心。只使用最近 45 天、最多 150 位不同画师，每位取最新有效的代表作特征，按时间衰减，样本收缩使用 n/(n+100)。弱中心的全局系数不超过显式负中心实际系数的 0.25 倍，独立封顶；按组标准化时不可把该弱信号重新放大。没有可用显式负例时，先仅启用画师级软降权。
- 一旦画师被明确加入或拒绝，即失效该画师的历史弱反馈，禁止同一事件同时产生显式与弱信号。旧轮次不凭响应、日志或未操作状态补造跳过。离线评估只以显式审阅作为真实标签。

## 落地与验收

1. 先上 15 位配额、取消自动补池、成年超额边界、榜单分数修正和漏斗统计。验证后台空闲不补位、刷新仍生成新批、旧补池任务无法发布、全年龄不足时成年仍守上限。
2. 实现年龄分类与全年龄召回、不同种子共现、5 次 ID 探测。比较分层缺额、来源及请求预算。
3. 上线曝光计时、幂等结算和画师级弱降权；覆盖未可见、未加载、后台标签页、快速刷新、移动端高卡片、失败换批、重复请求与显式审阅竞争。
4. 在相同候选池对比旧回归、统一标签特征后的回归、相似度加共现。分开测显式负例与弱中心，验证 150 条弱样本不会冲淡显式负例，确认跨轮仍可展示跳过画师。用户实际审阅结果才进入排序验收。
5. 新轮次预算与评分分版本保存。在途普通轮次沿用已冻结的旧预算；自动补池任务按新规则停用。回滚通过切换新轮次评分与弱反馈开关，原有轮次和审阅数据保留。
