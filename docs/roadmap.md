# 路线图导航

详细任务、状态和验收统一维护在 [开发计划](development-plan.md)，技术契约见 [详细设计](detailed-design.md)。本文件不重复维护任务复选框。

| 阶段 | 目标 | 当前状态 |
| --- | --- | --- |
| M0 | 工程初始化与设计文档 | 已完成 |
| M1 | SQLite、管理鉴权、持久任务、Pixiv 客户端 | 核心离线完成；新增依赖 Docker 验证进行中 |
| M2 | 关注同步、采集名单、作品目录、管理基础页 | 离线完成；真实账号待验收 |
| M3 | 筛选选图、固定图片转发、PicHub 接入 | 进行中：PicHub 联调与容器验收未完成 |
| M4 | 画师推荐、预览确认、作品偏好 | 核心离线完成；完整实网流程进行中 |
| M5 | PicHub 反馈回传、维护与性能优化 | 后续增强 |

M3 是最小接入目标；M4 覆盖用户要求的完整流程。下一步：本轮 Docker 验证与独立测试账号下的 Pixiv/PicHub 联调，不能把离线测试当作实网验收。
