# 实施计划

## 阶段 0：项目初始化

- [x] 独立目录、Go module、Git 本地管理
- [x] API 入口、环境配置、结构化日志、优雅退出
- [x] 存活检查与版本接口
- [x] 基础测试、开发命令、架构边界

## 阶段 1：目录与最小供图链路

- [ ] SQLite 驱动、迁移、画师/作品/图片页模型
- [ ] 可替换的 Pixiv 客户端，认证与限速
- [ ] 同步关注、手动添加画师、采集名单
- [ ] 后台增量采集，持久游标和失败重试
- [ ] 元数据过滤与固定图片地址
- [ ] 随机 JSON 接口和可选图片流转发
- [ ] PicHub 配置接入验证

验收：一批确认的画师能生成图片目录，多页不重复入库；PicHub 能选图、下载并显示；重启后不丢失目录与采集进度。

## 阶段 2：推荐与确认

- [ ] 标签画像、多源候选、可解释排序
- [ ] 画师候选页与作品预览
- [ ] 确认/拒绝/屏蔽，确认后自动采集
- [ ] 标签、AI/R18、尺寸等个人偏好规则

验收：未确认候选不进入正式供图范围；拒绝/屏蔽持久有效；用户可追溯推荐原因。

## 阶段 3：反馈与运维

- [ ] 作品级喜欢/排除、作者均衡、近期去重
- [ ] Pixiv 链接失效检测与修复
- [ ] PicHub 稳定作品身份与反馈回传（另行修改 PicHub）
- [ ] 管理鉴权、部署文件、备份恢复、运行状态

验收：反馈改变作品选择，不把预取作为喜欢；凭据不经公开接口暴露；目录与任务可恢复。
