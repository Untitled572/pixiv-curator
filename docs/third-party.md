# 第三方组件

## 可选本机登录

- 项目：[eggplants/get-pixivpy-token](https://github.com/eggplants/get-pixivpy-token)
- 版本：gppt 5.1.0，MIT，PyPI wheel SHA256：`6eefee83ada3423ef7e53c5ae54501c0eb26a4d1f65b26f6dfff76f250d43194`。
- 方式：由本机脚本安装，通过独立 Python 进程调用公开库接口；未复制库实现或内置其 OAuth 客户端密钥。
- 传递依赖见 `scripts/requirements-login.txt`，各包许可随其安装元数据提供。
